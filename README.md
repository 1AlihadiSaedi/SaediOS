## فارسی
**ساعدی‌ او اس** یا **SaediOS** یک کرنل آموزشی ساده است که برای یادگیری مفاهیم پایه سیستم‌عامل و معماری x86/x86_64 توسعه داده می‌شود.  
این پروژه در حال حاضر در نسخه آزمایشی قرار دارد و شامل یک بوت‌لودر اختصاصی و قابلیت سوئیچ به Long Mode است.  

### وضعیت پروژه
- نسخه فعلی: آزمایشی (Beta)  
- در حال توسعه: بوت‌لودر ثانویه و پشتیبانی کامل از Long Mode

## English
**SaediOS** is a simple educational kernel designed for learning basic operating system concepts and x86/x86_64 architecture.  
The project is currently in its experimental stage, featuring a custom bootloader and preliminary support for Long Mode.  

### Project Status
- Current version: Experimental (Beta)  
- In development: Secondary bootloader and full Long Mode support
